# Vector Database Project

A simple and efficient Vector Database project built using Python for storing, searching, and retrieving vector embeddings. This project demonstrates how vector similarity search works and can be used in AI, Machine Learning, Recommendation Systems, Semantic Search, and Retrieval-Augmented Generation (RAG) applications.

## Features

- Store high-dimensional vectors
- Perform similarity search
- Cosine similarity implementation
- Fast vector retrieval
- Simple and beginner-friendly implementation
- Python-based project

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn (if used)

Load dataset

Vector Similarity

This project mainly uses cosine similarity for finding the nearest vectors.

## Cosine Similarity Formula:

cos(θ)=
∥A∥∥B∥
A⋅B
	​


## Where:

A = First vector
B = Second vector
θ = Angle between vectors
